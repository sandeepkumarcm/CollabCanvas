# 🖊️ CollabCanvas

**CollabCanvas** is a real-time collaborative whiteboard built by **Sandeepkumar C M** for teams, classrooms, and creative professionals.  
It allows multiple users to draw, write, and brainstorm together seamlessly on a shared online canvas.

---

## 🚀 Features
- 🎨 Real-time drawing and board synchronization using **WebSockets**
- 👥 Multi-user collaboration with persistent storage
- 🧩 Clean and responsive UI using **HTML, CSS, JavaScript**
- ⚙️ Backend powered by **Node.js** and **Express**
- 🐳 Optional Docker setup for easy deployment
- 🔐 JSON Web Token (JWT) authentication support

---

## 🛠️ Tech Stack
| Layer | Technology |
|--------|-------------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js, Express |
| Real-time Communication | WebSockets |
| Database | File-based storage (server-data) |
| Deployment | Docker |

---

## ⚡ Getting Started
To run CollabCanvas locally:

```bash
# Clone the repository
git clone https://github.com/sandeepkumarcm/CollabCanvas.git
cd CollabCanvas

# Install dependencies
npm install

# Start the server
npm start
